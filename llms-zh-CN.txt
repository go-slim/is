# Is 包 - 综合验证库

## 概述

`is` 包是 Go 语言的综合验证库，提供各种数据类型和格式的广泛验证功能。该包设计为数据验证的完整工具包，从基本字符串格式到复杂网络地址和文件系统检查。

## 核心架构

### 验证分类

包按几个验证类别组织：

#### 字符串和文本验证
- **电子邮件验证**：符合 RFC 5322 标准的电子邮件地址验证
- **电话验证**：E.164 国际格式和中国大陆手机号码
- **字符验证**：ASCII、字母、字母数字，支持 Unicode
- **编码验证**：Base64、Base64URL、URL 编码、HTML 编码
- **哈希验证**：MD4、MD5、SHA256、SHA384、SHA512 哈希格式验证
- **标识符验证**：UUID（v1、v3、v4、v5）、ULID、语义版本

#### 网络和地址验证
- **IP 地址**：IPv4、IPv6 和通用 IP 验证
- **MAC 地址**：硬件地址验证
- **URL**：全面的 URL 格式验证

#### 颜色和视觉验证
- **颜色格式**：HEX、RGB、RGBA、HSL、HSLA 颜色验证
- **十六进制验证**：通用十六进制字符串验证

#### 时间和地理验证
- **日期时间验证**：使用自定义布局的灵活日期时间解析
- **时区验证**：IANA 时区数据库验证
- **地理坐标**：纬度和经度验证

#### 文件系统验证
- **文件验证**：检查路径是否指向现有文件
- **目录验证**：检查路径是否指向现有目录

#### 通用数据验证
- **类型验证**：数字、布尔值、空值检查
- **集合验证**：长度、范围和成员资格测试
- **比较操作**：完整的比较函数套件

## 主要特性

### Unicode 支持
包通过专用函数提供出色的 Unicode 支持：
- `AlphaUnicode()` 和 `AlphanumericUnicode()` 用于国际化文本
- 正确处理重音字符和非拉丁脚本
- 区分大小写的 Unicode 感知比较

### 类型安全
广泛使用泛型和反射进行类型安全操作：
- 数字、布尔值和字符串验证的泛型函数
- 自动类型转换和比较
- 比较中混合类型的优雅处理

### 性能优化
- 为常用模式预编译正则表达式
- 高效的反射使用与适当缓存
- 验证函数中的最小分配

## 使用模式

### 基本验证
```go
// 电子邮件验证
is.Email("user@example.com")     // true

// 电话号码验证
is.E164("+14155552671")         // true
is.PhoneNumber("13800138000")   // true

// 字符验证
is.Alpha("Hello")               // true
is.Alphanumeric("Test123")      // true
```

### 高级验证
```go
// 网络验证
is.IPv4("192.168.1.1")          // true
is.IPv6("2001:db8::1")          // true
is.MAC("00:00:5e:00:53:01")    // true

// 颜色验证
is.HEXColor("#FF0000")          // true
is.RGB("rgb(255, 0, 0)")        // true
is.HSL("hsl(0, 100%, 50%)")    // true

// 哈希验证
is.SHA256("2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c") // true
```

### 比较验证
```go
// 范围验证
is.Between(5, 1, 10)           // true
is.LengthBetween("hello", 3, 8) // true

// 成员资格验证
is.OneOf("apple", []any{"apple", "banana", "orange"}) // true

// 比较操作
is.GreaterThan(10, 5)          // true
is.Equal("hello", "hello")     // true
```

包遵循 Go 错误处理约定：
- 验证结果的布尔返回值
- 程序员错误的恐慌条件（例如，无效范围）
- 无效输入类型的优雅处理

## 集成指南

### 输入清理
在验证前始终清理输入：
```go
email := strings.TrimSpace(userInput)
if is.Email(email) {
    // 处理有效电子邮件
}
```

### 验证链
结合多个验证进行全面检查：
```go
func ValidateUserInput(input string) bool {
    return is.NotEmpty(input) &&
           is.AlphanumericUnicode(input) &&
           is.LengthBetween(input, 3, 50)
}
```

### 自定义验证
使用现有模式通过创建自定义验证器扩展包：
```go
func CustomID(id string) bool {
    return is.Length(id, 8, "=") && is.Alphanumeric(id)
}
```

## 性能考虑

- 在可能时使用特定验证函数（例如 `IPv4()`）而不是通用函数
- 为重复检查缓存验证结果
- 考虑在热路径中反射繁重函数的性能影响

## 安全说明

- 哈希验证函数仅验证格式，不验证密码学完整性
- 文件系统验证函数与实际文件系统交互
- 除了清理输入外，始终验证输入

## 兼容性

包与 Go 1.18+ 兼容，除标准库外不需要外部依赖。所有函数设计为并发使用安全。
